# news-to-x-post

把外部新闻/产品通报素材提炼成 X 发布稿（一条推文 × 三个风格版本）。格式定义全部内置在 skill 里，不依赖任何外部仓库；在 knowledge-garden 库中使用时按其目录约定落盘。

## 安装

```bash
npx skills add zhengzhuangpro/skills --skill news-to-x-post
```

## 使用

安装后，直接对 Claude 说：

- "把这条新闻总结成发布贴，9月21日"
- "总结成发布稿，X 版"
