# tool-site-design-system

为工具类、产品类官网提供终端美学风格的完整双主题设计系统。包含墨灰色彩系统、终端窗口组件、动画效果等。

## 安装

```bash
npx skills add zhengzhuangpro/skills --skill tool-site-design-system
```

## 使用

安装后，当你说以下内容时会自动触发：

- "帮我做一个工具产品的落地页"
- "做一个终端风格的产品官网"
- "build a tool landing page"
- "create a terminal-style product site"
- "tool website with terminal aesthetic"

## 适用场景

- 工具类产品落地页
- CLI 工具 / 开发者产品官网
- 任何需要"终端美学"或"黑客风格"的站点
- 设计要求提到：等宽字体、极简、技术感
- 双主题站点（明暗切换），基于 CSS 自定义属性

## 技术栈

- **框架**: Next.js (App Router)
- **样式**: Tailwind CSS v4
- **主题**: next-themes（默认亮色，支持明暗切换）
- **字体**: Geist + Geist Mono
- **图标**: Lucide React
