# pre-publish-factcheck

发文前把文章里的产品声明和项目代码逐条对账：修掉超卖和失实、核查配图错别字与图文一致性、清理 AI 味，并同步编辑器版与底稿。

## 安装

```bash
npx skills add zhengzhuangpro/skills --skill pre-publish-factcheck
```

## 使用

安装后，直接对 Claude 说：

- "这篇文章要发公众号当产品首发，帮我看看符不符合项目实际"
- "发文前帮我跟代码对个账"
- "去掉这篇文章的 AI 味"
