# humanize-article

文章去 AI 味：按模式清单清理模板化表达、翻译腔、运营黑话（模式是线索不是词表，保留信息、确定程度和作者声音）；发文前把文章里的产品声明和项目代码逐条对账，修掉超卖和失实、核查配图错别字与图文一致性，并同步编辑器版与底稿。

## 安装

```bash
npx skills add zhengzhuangpro/skills --skill humanize-article
```

## 使用

安装后，直接对 Claude 说：

- "去掉这篇文章的 AI 味"
- "这篇文章要发公众号当产品首发，帮我看看符不符合项目实际"
- "发文前帮我跟代码对个账"
