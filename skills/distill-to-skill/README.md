# distill-to-skill

把在别处写的内容（笔记、聊天记录、文档、随手记）提炼成一个**独立自包含**的 skill——不依赖任何仓库或外部文件，放到任意电脑、任意 AI 助手都能拿来就用。

## 安装

```bash
npx skills add zhengzhuangpro/skills --skill distill-to-skill
```

## 使用

安装后，直接对 Claude 说：

- "把我这篇笔记提炼成 skill"
- "总结成 skill"
- "distill to skill"
