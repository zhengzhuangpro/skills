# dev-terminal-design-system

为开发者工具、CLI 产品、技术文档站点提供暗黑终端美学风格的完整设计系统。包含墨灰色彩系统、终端窗口组件、动画效果等，灵感来自 helmagent.dev。

## 安装

```bash
npx skills add zhengzhuang/skills --skill dev-terminal-design-system
```

## 使用

安装后，当你说以下内容时会自动触发：

- "帮我做一个开发者工具的落地页"
- "做一个暗黑风格的终端页面"
- "build a developer landing page"
- "create a terminal-style website"
- "developer product site with dark theme"

## 适用场景

- CLI 工具 / 开发者产品落地页
- 面向工程师的技术产品官网
- 任何需要"终端美学"或"黑客风格"的站点
- 设计要求提到：暗色主题、等宽字体、开发者向、极简、技术感

## 技术栈

- **框架**: Next.js (App Router)
- **样式**: Tailwind CSS v4
- **主题**: next-themes（默认暗色）
- **字体**: Geist + Geist Mono
- **图标**: Lucide React
